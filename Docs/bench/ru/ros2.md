# ROS 2

Мост ROS 2 превращает датчики симулятора в обычные топики и принимает каналы пульта. Сам мост это узел на Python,
который подключается к симулятору через SDK, поэтому в ROS 2 доступно ровно то же, что и в SDK.

Поддерживаются **Humble** и **Jazzy**. Исходники: `bench/ros2` (пакеты `ushqyr_msgs` и `ushqyr_ros2_bridge`).

## Быстрый старт в Docker

```
ushqyr-bench build-images --ros2 jazzy
ushqyr-bench submit-check bench/examples/color_pid_ros2 --logs
```

Для Humble: `build-images --ros2 humble` и `submit-check ... --build-arg ROS_DISTRO=humble`.

Пример `bench/examples/color_pid_ros2` это то же решение `color_pid`, но все данные оно получает из топиков.

## Запуск без Docker

Нужен установленный ROS 2 и SDK (`pip install ./bench/sdk/python`).

```
cd bench/ros2 && colcon build && source install/setup.bash
ros2 run ushqyr_ros2_bridge bridge
```

Симулятор должен быть запущен в режиме AI Bench. Адрес и токен мост берет из `USHQYR_BENCH_HOST`,
`USHQYR_BENCH_PORT`, `USHQYR_BENCH_TOKEN` или из параметров `host`, `port`, `token`.

## Топики

Мост публикует:

| Топик | Тип | Что это |
|---|---|---|
| `/clock` | `rosgraph_msgs/Clock` | Время симулятора |
| `ushqyr/camera/image_raw` | `sensor_msgs/Image` | Камера, `rgb8`, 30 Гц |
| `ushqyr/camera/camera_info` | `sensor_msgs/CameraInfo` | Калибровка камеры, с каждым кадром |
| `ushqyr/imu/data_raw` | `sensor_msgs/Imu` | Гироскоп и акселерометр, 500 Гц, без ориентации |
| `ushqyr/tof/range` | `sensor_msgs/Range` | Дальномер вниз; `inf`, когда измерения нет |
| `ushqyr/scan` | `sensor_msgs/LaserScan` | 2D-лидар; луч 0 смотрит вперед, углы растут влево |
| `ushqyr/battery` | `sensor_msgs/BatteryState` | Напряжение батареи |
| `ushqyr/status` | `ushqyr_msgs/AttemptStatus` | Раз в шаг управления, после сообщений датчиков этого шага |
| `ushqyr/info` | `std_msgs/String` | Приветствие симулятора в JSON (хранится для новых подписчиков) |

Мост слушает:

| Топик | Тип | Что это |
|---|---|---|
| `ushqyr/rc` | `ushqyr_msgs/RcChannels` | 16 каналов в микросекундах (1000–2000) |
| `ushqyr/joy` | `sensor_msgs/Joy` | Оси: крен, тангаж, газ (0..1), рыскание. Кнопки: 0 арм, 1 Horizon, 2 Acro |

Каналы `RcChannels`: 0 крен, 1 тангаж, 2 газ, 3 рыскание, 4 AUX1 (арм), 5 AUX2 (режим полета). Арминг срабатывает,
только когда AUX1 поднимается при газе не выше 1050.

Система координат корпуса: x вперед, y влево, z вверх (REP 103). Метки времени во всех сообщениях это время симулятора.

## Калибровка камеры

В `camera_info` матрица `K` обычная, а модель искажений своя: `distortion_model = "ushqyr_radial_k1"`, `D = [k1]`.
Это **не** `plumb_bob`. Модель переводит точку искаженной картинки в прямую:
`x_u = x_d · (1 + k1 · r_d²)` в нормированных координатах. Стандартные узлы исправления искажений ROS с ней не
работают; используйте формулу напрямую (пример: `ColorPid._ray` в `color_pid.py`).

## Как идет время

Попытка начинается, когда мост получает первое сообщение на `ushqyr/rc` или `ushqyr/joy` (параметр `wait_for_rc`).
Пока вы не готовы, шлите «дизарм»; до этого топик `ushqyr/info` уже доступен.

В синхронном режиме на каждом шаге мост публикует датчики и ждет новое сообщение RC не дольше `sync_wait` секунд
реального времени (по умолчанию 0,2). Если сообщение не пришло, шаг проходит без пакета, как при потере связи; после
`failsafe_ms` без пакетов моторы отключаются.

Удобная схема для узла: на каждое сообщение `ushqyr/status` делать один шаг расчета и отправлять одно сообщение RC.

Когда попытка закончилась, `ushqyr/status` приходит с `running = false`, и мост завершается. Ваш узел тоже должен
завершиться, иначе контейнер не остановится сам.

## Параметры моста

| Параметр | По умолчанию | Что это |
|---|---|---|
| `host`, `port`, `token` | из окружения | Где симулятор |
| `connect_wait` | 60 | Сколько секунд пытаться подключиться |
| `wait_for_rc` | true | Начинать попытку по первому сообщению RC |
| `sync_wait` | 0.2 | Сколько ждать RC на каждом шаге (синхронный режим) |
| `seed` | не задан | Тренировочный режим: зерно шума датчиков |

## В контейнере решения

Узлы видят только друг друга внутри своего контейнера. Журналы ROS 2 пишутся в `/tmp`, потому что файловая система
только для чтения. Образ с ROS 2 занимает около 2,5 ГБ.

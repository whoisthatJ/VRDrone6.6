# AI Bench: документация

AI Bench это режим симулятора Ushqyr, в котором дроном управляет программа. Она получает только данные бортовых
датчиков и отвечает каналами пульта. Программы команд пролетают трассу из LED-ворот; чем больше ворот за отведенное
время, тем выше место.

## С чего начать

1. Пройдите [быстрый старт](quickstart.md): пример должен сам пролететь трассу.
2. Прочитайте [правила](rules.md) и [дрон и датчики](drone.md).
3. Скопируйте пример `bench/examples/color_pid` и меняйте его.
4. До отправки проверьте решение командой `ushqyr-bench submit-check` ([Docker](docker.md)).

## Что еще не окончательно

- Модель дрона организаторов временная: она не откалибрована по реальному дрону (`calibrated=false` в приветствии).
- Лимиты для решений (память, процессор, размер образа), число попыток и число трасс назначают организаторы.
  Числа на этих страницах это значения по умолчанию.

# Python SDK

Пакет `ushqyr_bench`. Исходники: `bench/sdk/python`. Нужен Python 3.9 или новее; зависимости: `numpy`, `msgpack`.

```
pip install ./bench/sdk/python
```

SDK ничего не прячет и не фильтрует: то, что режим не разрешает, симулятор просто не отправляет. Клиент на другом
языке можно написать по [protocol.md](protocol.md).

## Подключение

```python
Sim.connect(host=None, port=None, token=None, truth=False, realtime=True, timeout=30.0, wait=0.0) -> Sim
```

| Аргумент | Значение |
|---|---|
| `host`, `port`, `token` | Где симулятор. Если не заданы, берутся из переменных окружения `USHQYR_BENCH_HOST` (`127.0.0.1`), `USHQYR_BENCH_PORT` (`5757`), `USHQYR_BENCH_TOKEN` (пусто) |
| `truth` | Только тренировка: добавлять в каждое наблюдение истинные координаты и счет |
| `realtime` | Только тренировка: `False` разрешает считать так быстро, как может компьютер. Результат тот же |
| `timeout` | Сколько секунд ждать ответа симулятора |
| `wait` | Сколько секунд повторять попытки подключения, пока симулятор запускается. В Docker ставьте `wait=120` |

В решении для отбора вызывайте `Sim.connect()` без адреса и токена: сервер передает их через переменные окружения.

`Sim` работает как менеджер контекста: `with Sim.connect() as sim:` закрывает соединение сам.

## Sim

| Поле | Что это |
|---|---|
| `sim.info` | Приветствие симулятора: словарь с режимом, дроном, частотами и калибровкой камеры (см. ниже) |
| `sim.mode` | `"training"` или `"competition"` |
| `sim.control_hz` | Шагов управления в секунду времени симулятора (100) |
| `sim.realtime` | `True`, если симулятор идет по настенным часам и не ждет `step()` |
| `sim.running` | `True`, пока попытка идет |
| `sim.status` | `"waiting"`, `"running"`, затем причина конца попытки |

| Метод | Что делает |
|---|---|
| `sim.reset(seed=None)` | Начинает попытку и возвращает первое наблюдение. Тренировка: сколько угодно раз, `seed` задает шум датчиков. Соревнование: один раз, `seed` не действует |
| `sim.step(rc)` | Отправляет один пакет каналов; симулятор делает один шаг и возвращает наблюдение. `sim.step(None)` делает шаг без пакета, как при его потере |
| `sim.done()` | Сообщает, что программа закончила. Попытка завершается статусом `finished` |
| `sim.send(rc)` | Режим реального времени: отправляет пакет и ничего не ждет |
| `sim.latest(wait=False)` | Режим реального времени: самое новое пришедшее наблюдение или `None`. С `wait=True` ждет следующее |
| `sim.ping(payload=0)` | Только тренировка: время обмена одним сообщением, секунды |
| `sim.close()` | Закрывает соединение |

До `reset()` вызывать `step()` нельзя: будет `BenchError("not_started")`.

## RC

```python
RC(roll=0.0, pitch=0.0, throttle=0.0, yaw=0.0, arm=False, mode="angle", aux=())
```

| Поле | Диапазон | Знак |
|---|---|---|
| `roll` | -1 … 1 | + вправо |
| `pitch` | -1 … 1 | + вперед (нос вниз) |
| `throttle` | 0 … 1 | |
| `yaw` | -1 … 1 | + вправо (по часовой стрелке, если смотреть сверху) |
| `arm` | `False` / `True` | тумблер AUX1 |
| `mode` | `"angle"`, `"horizon"`, `"acro"` | тумблер AUX2 |
| `aux` | до 10 целых чисел | запасные каналы, симулятор их не читает |

Значения вне диапазона обрезаются. `NaN` заменяется нулем.

`RC.from_us([1500, 1500, 1000, 1500, 2000, 1000])` задает каналы прямо в микросекундах (1000 … 2000) в порядке roll,
pitch, throttle, yaw, AUX1, AUX2.

`rc.channels()` возвращает 16 значений в микросекундах: то, что уйдет симулятору.

## Observation

То, что возвращают `reset()`, `step()`, `done()` и `latest()`.

| Поле | Тип | Что это |
|---|---|---|
| `obs.t` | float | Время симулятора от старта, секунды |
| `obs.tick` | int | Шагов физики от старта (1000 в секунду) |
| `obs.running` | bool | `False`, когда попытка закончилась |
| `obs.status` | str | `running` или причина конца: `finished`, `time_limit`, `stuck`, `disconnected` |
| `obs.camera` | `Camera` | Последний кадр |
| `obs.imu` | `Imu` | Все измерения IMU с прошлого наблюдения |
| `obs.tof` | `Tof` | Дальномер вниз |
| `obs.lidar` | `Lidar` | Последний полный оборот лидара |
| `obs.battery` | `Battery` | Напряжение |
| `obs.truth` | dict или `None` | Только тренировка с `truth=True`: `position` и `velocity` как [восток, север, вверх] в метрах, `points`, `score_time` |

Датчики работают со своей частотой, поэтому в большинстве наблюдений новые только измерения IMU. У остальных
датчиков есть поле `new`: `True`, если это наблюдение принесло новое значение. Пока нового нет, в поле лежит прошлое.

### Camera

| Поле | Что это |
|---|---|
| `image` | `numpy`-массив высота × ширина × 3, `uint8`, RGB, верхняя строка первой. `None` до первого кадра |
| `t` | Время симулятора, когда кадр снят. До программы он доходит позже на задержку камеры |
| `seq` | Номер кадра |
| `new` | Этот кадр новый |

Для OpenCV переведите цвета: `cv2.cvtColor(obs.camera.image, cv2.COLOR_RGB2BGR)`.

### Imu

| Поле | Что это |
|---|---|
| `t` | Массив времен измерений, длина n |
| `gyro` | n × 3, рад/с: x крен вправо +, y нос вниз +, z поворот влево + |
| `accel` | n × 3, м/с², кажущееся ускорение: в покое на ровном полу (0, 0, +9,81) |

`len(obs.imu)` это число измерений (обычно 5 на шаг). Оси корпуса: x вперед, y влево, z вверх.

### Tof, Lidar, Battery

| Поле | Что это |
|---|---|
| `tof.range`, `tof.valid` | Метры до поверхности внизу; `0` и `False`, когда вне диапазона |
| `lidar.ranges` | Массив дальностей в метрах, по одной на луч; `0` = ничего не измерено; `None` до первого скана. Луч `k` смотрит на `k · angle_step` от оси «вперед», углы растут влево |
| `lidar.t` | Время конца оборота |
| `battery.voltage` | Вольты |
| `.t`, `.new` | Есть у каждого: время измерения и признак нового значения |

## Приветствие: sim.info

```python
cam = sim.info["sensors"]["camera"]
fx, fy, cx, cy = cam["fx"], cam["fy"], cam["cx"], cam["cy"]
k1 = cam["distortion"]["k1"]
```

| Ключ | Что это |
|---|---|
| `mode`, `time_mode`, `control_hz`, `time_limit` | Режим, `sync` или `realtime`, частота шага, лимит времени попытки |
| `track` | Только тренировка: `id` и `hash` трассы |
| `drone` | `class` (`ai_mission` или `ai_core`), `name`, `calibrated` |
| `rc` | `channels`, `rate_hz`, `latency_ms`, `failsafe_ms` |
| `sensors.camera` | `width`, `height`, `fps`, `hfov_deg`, `tilt_deg`, `latency_ms`, `fx`, `fy`, `cx`, `cy`, `distortion`, `mount` |
| `sensors.lidar` | `rate_hz`, `rays`, `min_m`, `max_m`, `angle_step_deg`. Нет ключа, если у дрона нет лидара |
| `sensors.imu`, `sensors.tof`, `sensors.battery` | Частоты и диапазоны |

## Ошибки

`BenchError` с полями `code` и `message`.

| `code` | Когда |
|---|---|
| `token` | Неверный токен |
| `not_allowed` | Сообщение запрещено в этом режиме (например, `ping` в соревновании) |
| `already_started` | Второй старт в режиме соревнования |
| `attempt_over` | Попытка этого запуска симулятора уже закончилась |
| `not_started` | `step()` до `reset()` |
| `timeout` | Симулятор не ответил за `timeout` секунд |
| `disconnected` | Симулятор закрыл соединение |
| `protocol` | Сообщение не по протоколу |

Если симулятор не запущен, `Sim.connect()` бросает обычный `ConnectionRefusedError` (или ждет, если задан `wait`).

## Режим реального времени

Если в правилах `time_mode: "realtime"`, симулятор идет по настенным часам и никого не ждет. `step()` тогда
отправляет пакет и возвращает самое новое наблюдение, пропуская накопившиеся. Измерения IMU из пропущенных
наблюдений сохраняются по порядку. Для своего цикла используйте `send()` и `latest()`.

## Тесты без симулятора

`ushqyr_bench.fake.FakeSim` это заглушка симулятора для модульных тестов вашего кода:

```python
from ushqyr_bench import Sim, RC
from ushqyr_bench.fake import FakeSim

with FakeSim() as fake, Sim.connect(port=fake.port) as sim:
    obs = sim.reset()
    obs = sim.step(RC(arm=True))
    assert fake.received[-1][4] == 2000     # AUX1
```

Она отдает маленькие серые кадры (64 × 48) и не моделирует полет: ею проверяют обмен, а не алгоритм.

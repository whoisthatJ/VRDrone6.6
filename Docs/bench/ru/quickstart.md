# AI Bench: быстрый старт

AI Bench это режим симулятора Ushqyr, в котором дроном управляет ваша программа. Она получает только то, что дают
датчики дрона (картинку FPV-камеры с аналоговым шумом, IMU, дальномер ToF, LiDAR, напряжение батареи), и отвечает
каналами пульта: throttle, roll, pitch, yaw. Координат дрона и ворот программа не получает.

Ниже: как за несколько минут запустить готовый пример, который сам пролетает трассу.

## Что нужно

- Windows 10 или 11, видеокарта уровня GTX 1650 или лучше.
- Python 3.9 или новее.
- Симулятор Ushqyr версии 1.2 или новее и папка `bench` из комплекта.

## 1. Установите SDK и пример

В папке с комплектом выполните:

```
pip install ./bench/sdk/python
pip install opencv-python
```

SDK зависит только от `numpy` и `msgpack`. OpenCV нужен примеру, а не SDK.

## 2. Запустите симулятор в режиме AI Bench

Любым из двух способов:

- В главном меню игры нажмите **AI Bench**.
- Или запустите из командной строки: `Ushqyr.exe -bench`

Откроется зал с трассой `H1_Oval` (6 ворот по овалу). Слева вверху написано «Ожидание программы на порту 5757».
Дрон стоит на стартовой площадке.

## 3. Запустите пример

```
python bench/examples/color_pid/color_pid.py --show
```

Дрон взлетит, найдет ворота по цвету подсветки и полетит по кругу. Что вы увидите:

- слева вверху: счетчик ворот и время попытки;
- справа внизу: картинка с бортовой камеры, ровно та, которую получает программа;
- в отдельном окне (ключ `--show`): та же картинка с рамкой вокруг найденных ворот.

Клавиша **C** переключает вид: камера за дроном или общий вид зала. **Esc** возвращает в меню.

Попытка длится 120 секунд. Чтобы остановиться после одного круга, добавьте `--points 6`.

## 4. Напишите свое решение

Минимальная программа:

```python
from ushqyr_bench import Sim, RC

with Sim.connect() as sim:
    obs = sim.reset()                       # дрон на старте, время с нуля
    for _ in range(15):                     # арминг: тумблер выключен...
        obs = sim.step(RC(arm=False))
    for _ in range(15):                     # ...затем включен при нулевом газе
        obs = sim.step(RC(arm=True))
    while sim.running:
        frame = obs.camera.image            # numpy, 480 x 640 x 3, RGB
        gyro, accel = obs.imu.gyro, obs.imu.accel
        height = obs.tof.range              # метры до пола, если obs.tof.valid
        scan = obs.lidar.ranges             # 360 дальностей по кругу, 0 = ничего не измерено
        rc = RC(throttle=0.56, pitch=0.1, arm=True)   # здесь ваш алгоритм
        obs = sim.step(rc)                  # симулятор делает один шаг (1/100 с)
```

Важное про управление:

- Каналы как на настоящем пульте. `roll`, `pitch`, `yaw` от -1 до 1, `throttle` от 0 до 1.
- **Арминг.** Полетный контроллер включает моторы, только если тумблер `arm` переключен из «выкл» во «вкл» при
  опущенном газе. Сначала отправьте несколько пакетов с `arm=False`, затем `arm=True` и `throttle=0`, и только
  потом добавляйте газ. Так сделано в примере.
- По умолчанию режим Angle (дрон сам держит горизонт): `pitch=0.2` это наклон вперед примерно на 9 градусов.
- Время в симуляторе идет только по вашим вызовам `step()`. Если программа думает долго, полет просто идет
  медленнее, результат от этого не меняется.

Начните с копии `color_pid.py`: класс `GateDetector` ищет ворота, класс `ColorPid` рулит.

## Трассы

Клавиша **T** открывает список трасс: шесть готовых (зал и паркинг) и ваши собственные. Кнопка «Изменить»
открывает редактор: ворота перетаскиваются мышью по плану, у каждых свой цвет подсветки. Редактор сам проверяет
трассу, а «Пробный полет» показывает, как ее пролетает пилот-оракул.

Объектив камеры дает бочкообразное искажение. Модель и коэффициент приходят в приветствии
(`sim.info["sensors"]["camera"]["distortion"]`), формула есть в `Docs/bench/protocol.md`; в примере ее учитывает
метод `_ray`.

## Тренировочный режим

Сейчас симулятор работает в тренировочном режиме. В нем дополнительно доступно:

- `sim.reset()` сколько угодно раз, с выбором зерна шума: `sim.reset(seed=7)`;
- истинные координаты и счет для отладки: `Sim.connect(truth=True)`, затем `obs.truth`;
- ускоренный прогон: `Sim.connect(realtime=False)`.

В режиме соревнования ничего из этого нет. Проверить пример на нескольких зернах шума:

```
cd bench/examples/color_pid
python evaluate.py --runs 10
```

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| `ConnectionRefusedError` | Симулятор не запущен в режиме AI Bench, либо занят порт 5757. Другой порт: `Ushqyr.exe -bench -bench-port 5800` и `set USHQYR_BENCH_PORT=5800` |
| Дрон стоит на месте, моторы молчат | Не выполнен арминг: см. выше |
| Дрон взлетает и падает | Газ висения около 0.56. Удерживайте высоту по `obs.tof.range` |
| `ModuleNotFoundError: cv2` | `pip install opencv-python` |

## Что в этой версии еще не готово

Модель вупера временная и не откалибрована по реальному дрону: в интерфейсе и в приветствии API она помечена
`calibrated=false`. Генерация датасетов, свой дрон из конфига (AI CORE), мост ROS 2 и запуск в Docker появятся на
следующих этапах. Пример `color_pid` уверенно проходит `H1_Oval`; на «восьмерке» и в паркинге он иногда
ошибается, это отправная точка, а не готовое решение.

Описание протокола для клиентов на других языках: `Docs/bench/protocol.md`.

# Если что-то не работает

## Установка

| Что видите | Что сделать |
|---|---|
| `python` или `pip` не найдены (Windows) | Установите Python с python.org и используйте `py -m venv .venv`, `py -m pip ...` |
| `error: externally-managed-environment` (Linux) | Ставьте в виртуальное окружение: `python3 -m venv .venv`, `source .venv/bin/activate` |
| `ModuleNotFoundError: ushqyr_bench` | Не включено окружение `.venv` или SDK не установлен: `pip install ./bench/sdk/python` |
| `ModuleNotFoundError: cv2` | `pip install opencv-python` |
| `ushqyr-bench` не найдена | `pip install ./bench/runner` в том же окружении |
| Симулятор не запускается на Linux | `chmod +x Ushqyr.x86_64`; проверьте, что установлен драйвер видеокарты |

## Подключение

| Что видите | Что сделать |
|---|---|
| `ConnectionRefusedError` | Симулятор не запущен в режиме AI Bench: в меню нажмите **AI Bench** или запустите с ключом `-bench`. На экране должно быть «Ожидание программы на порту 5757» |
| Порт 5757 занят | `Ushqyr.exe -bench -bench-port 5800`, а программе задайте `USHQYR_BENCH_PORT=5800` |
| `BenchError: token` | Симулятор запущен с токеном (`-bench-token`). Задайте тот же в `USHQYR_BENCH_TOKEN` |
| `BenchError: attempt_over` | В режиме соревнования один запуск симулятора это одна попытка. Запустите симулятор заново |
| `BenchError: already_started` | В режиме соревнования `reset()` вызывается один раз |
| `BenchError: not_allowed` | Сообщение запрещено в режиме соревнования (например, `ping`) |
| Вторая программа «выбила» первую | К симулятору подключается одна программа. Новое подключение заменяет старое |

## Полет

| Что видите | Что сделать |
|---|---|
| Дрон стоит, моторы молчат | Не выполнен арминг. Сначала пакеты с `arm=False`, затем `arm=True` при `throttle=0`, и только потом газ |
| Моторы выключились в полете | Failsafe: 500 мс не было пакетов. Вызывайте `step()` на каждом шаге. Чтобы включить моторы снова, выключите и включите `arm` при нулевом газе |
| Дрон взлетает и падает | Газ висения около 0,56. Держите высоту по `obs.tof.range` |
| Дрон летит назад или вбок | Проверьте знаки: `pitch` + это вперед, `roll` + вправо, `yaw` + вправо |
| Попытка закончилась `stuck` | Дрон 10 секунд не двигался. Обычно он лежит после удара или программа не дает газ |
| Попытка закончилась `timeout` | Программа не ответила за 10 секунд реального времени на шаг. Ищите зависание или слишком долгий расчет |
| `obs.camera.image` это `None` | Кадров еще не было. Первый приходит с первым наблюдением после `reset()` |
| Цвета кадра в OpenCV перепутаны | Кадр в RGB, а OpenCV ждет BGR: `cv2.cvtColor(image, cv2.COLOR_RGB2BGR)` |
| Ворота на картинке «гнутся» у краев | Это бочкообразное искажение объектива. Формула есть в [drone.md](drone.md) |
| Детектор находит ворота хуже вдали от старта | Аналоговый видеоканал портится с расстоянием. Учите детектор на кадрах симулятора ([dataset.md](dataset.md)) |
| Полет идет медленнее реального времени | В синхронном режиме симулятор ждет вашу программу. На результат это не влияет |
| Один и тот же запуск дает разный результат | Проверьте, что зерно одно и то же (`sim.reset(seed=...)`) и что программа сама не использует случайность или настенные часы |

## Docker

| Что видите | Что сделать |
|---|---|
| `the Docker engine is not running` | Запустите Docker Desktop (Windows) или службу Docker (Linux) |
| `the base image ... is not built yet` | `ushqyr-bench build-images` |
| `the attempt produced no result` | Решение не подключилось или упало. Смотрите вывод с ключом `--logs` |
| `the solution did not exit when the attempt ended` | Программа должна завершаться сама: выходите из цикла, когда `sim.running` стал `False` |
| Ошибка `pip install` или загрузки весов во время полета | В контейнере нет интернета. Ставьте все в `Dockerfile`, веса кладите в образ |
| `Read-only file system` | Писать можно только в `/tmp` |
| Решение убито по памяти | Лимит 4 ГБ. Уменьшите модель или размер пакета |
| Проверка идет десятки минут | Симулятор рисует без видеокарты. См. «Время» в [docker.md](docker.md) |
| Решение подключается раньше, чем симулятор готов | `Sim.connect(wait=120)` |

## ROS 2

| Что видите | Что сделать |
|---|---|
| Топиков нет | Мост не запущен или не подключился: проверьте `USHQYR_BENCH_HOST`, `USHQYR_BENCH_PORT` и что симулятор в режиме AI Bench |
| Попытка не начинается | Мост ждет первое сообщение на `ushqyr/rc` или `ushqyr/joy` |
| Моторы отключаются | Узел шлет команды слишком редко: мост ждет команду не дольше 0,2 с на шаг, затем шаг идет без пакета |
| Стандартное исправление искажений дает неверную картинку | Модель искажений не `plumb_bob`. См. [ros2.md](ros2.md) |
| Контейнер не завершается после попытки | Ваш узел должен завершиться, когда `ushqyr/status` пришел с `running = false` |

## Если не помогло

Соберите и пришлите организаторам:

- версию симулятора (она есть в приветствии: `sim.info["sim"]`) и операционную систему;
- команду, которую запускали, и полный текст ошибки;
- для Docker: вывод `ushqyr-bench submit-check ... --logs`.

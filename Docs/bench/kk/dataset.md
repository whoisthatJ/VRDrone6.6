# Датасеттер

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

Симулятор қақпалары бар белгіленген кадрларды өзі жасайды. Олар ұшу кезіндегі камерамен түсірілген: объективімен,
экспозициясымен және аналогтық бейне арнасымен. Детекторды дәл осы кадрларда оқыту керек.

Датасеттер тек жаттығу режимінде қолжетімді.

## Қалай жасау керек

**Қолданбада.** **T** пернесі, содан кейін керекті трассаның жанындағы «Датасет»: нәтижелер бумасына 500 кадр жазылады.
Датасет дайын болғанда жол көрсетіледі.

**Командалық жолдан.** Құралдар қажет: `pip install ./bench/runner`.

```
ushqyr-bench dataset --sim Ushqyr.exe --track H1_Oval --out data/h1 --count 2000 --seed 7 --masks
ushqyr-bench dataset-check data/h1 --draw 100
```

| Кілт | Әдепкі мән | Бұл не |
|---|---|---|
| `--sim` | міндетті | Симуляторға апаратын жол |
| `--track` | `H1_Oval` | Дайын трассаның атауы немесе трасса файлының жолы |
| `--out` | міндетті | Қайда жазу керек |
| `--count` | 500 | Кадр саны |
| `--seed` | 1 | Тұқым (seed). Бір тұқым бір датасетті береді |
| `--profile` | `strong` | Сахнадағы жағдайларды өзгерту: `none`, `mild`, `strong` |
| `--masks` | өшірулі | Маскаларды да жазу |

## Кадрлардың ішінде не бар

- **Камера орындары.** Кадрлардың 70%-ы оракул-пилоттың ұшу жолының бойында кездейсоқ ығысулармен түсірілген, 30%-ы
  алаңның кездейсоқ жерлерінен түсірілген.
- **Сахна.** Әр 25 кадр сайын сахна өзгереді: қақпалардың жылжуы, жарық, еден мен қабырға материалдары, қабырға
  жанындағы заттар, жарықтандыру (LED) түстері ([tracks.md](tracks.md) ішіндегі «Жағдайларды өзгерту» бөлімін қараңыз).
- **Кескін.** Әр кадрда бейне арнасы кедергілерінің күші, экспозиция және қозғалыстан болатын бұлдырлау өзінше.

## Белгілеу

Кадрдағы әр қақпа үшін:

| Өріс | Бұл не |
|---|---|
| Жақтау | Қақпаны қоршайтын тіктөртбұрыш |
| Қақпа ойығының төрт бұрышы | Камераға қараған жағында, мына ретпен: жоғарғы сол, жоғарғы оң, төменгі оң, төменгі сол |
| Бұрыштың көрінуі | 0 = кадрдан тыс, 1 = жабылған, 2 = көрінеді |
| `occluded`, `truncated` | Қақпа ішінара жабылған; қақпа кадр шетімен кесілген |
| Қашықтық | Қақпаға дейінгі метр |

## Форматтар

| Формат | Файлдар |
|---|---|
| YOLO | `images/`, `labels/`, `data.yaml`; жақтау және түйінді нүктелер («pose» орналасуы) |
| COCO | `annotations/instances_train.json`, `instances_val.json`, `instances_test.json` |
| Маскалар (`--masks`) | Әр кадрға бір PNG: 0 = қақпа емес, n = трассаның n-ші қақпасы |

80 / 10 / 10 бөлінуі (оқыту, тексеру, тест) тұқым арқылы беріледі.

## Белгілеуді тексеру

Симулятор әр кадрды екінші рет салады: жарық өшірілген, әр қақпа өз түсімен жарқырайды. Кадрға толық сыйған әр
қақпаның жақтауы боялған нүктелердің контурымен 2 пиксель дәлдікпен сәйкес келуі керек, ал әрбір көрінетін бұрыш өз
қақпасының үстінде жатуы керек. Есептегіштер `dataset.json` файлына жазылған.

`dataset-check` файлдарды өзара салыстырады және сәйкестік 98%-дан аз болса, қатемен аяқталады. `--draw N` кілтімен ол
кездейсоқ N кадрдың үстіне белгілеуді салып, `check/` бумасына жазады (OpenCV қажет): оқытудан бұрын оларды өз көзіңізбен
қарап шығыңыз.

## Кеңестер

- Датасеттерді бірнеше трассада, залда да, паркингте де жасаңыз: ол жерлерде жарық пен фон әртүрлі.
- Іріктеу трассалары жасырын. Деректер неғұрлым алуан түрлі болса, детектор таныс кескінге соғұрлым аз тәуелді болады.
- Деректерден кедергілерді алып тастамаңыз: ұшу кезінде олар болады.

# ROS 2

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

ROS 2 көпірі симулятор датчиктерін кәдімгі топиктерге айналдырады және пульт арналарын қабылдайды. Көпірдің өзі Python-да
жазылған түйін. Ол симуляторға SDK арқылы қосылады, сондықтан ROS 2-де SDK-дегімен дәл бірдей нәрселер қолжетімді.

**Humble** және **Jazzy** қолдау табады. Бастапқы код: `bench/ros2` (`ushqyr_msgs` және `ushqyr_ros2_bridge` пакеттері).

## Docker-де жылдам бастау

```
ushqyr-bench build-images --ros2 jazzy
ushqyr-bench submit-check bench/examples/color_pid_ros2 --logs
```

Humble үшін: `build-images --ros2 humble` және `submit-check ... --build-arg ROS_DISTRO=humble`.

`bench/examples/color_pid_ros2` мысалы сол `color_pid` шешімі, бірақ ол барлық деректі топиктерден алады.

## Docker-сіз іске қосу

Орнатылған ROS 2 және SDK қажет (`pip install ./bench/sdk/python`).

```
cd bench/ros2 && colcon build && source install/setup.bash
ros2 run ushqyr_ros2_bridge bridge
```

Симулятор AI Bench режимінде іске қосылған болуы керек. Көпір мекенжай мен токенді `USHQYR_BENCH_HOST`,
`USHQYR_BENCH_PORT`, `USHQYR_BENCH_TOKEN` айнымалыларынан немесе `host`, `port`, `token` параметрлерінен алады.

## Топиктер

Көпір мыналарды жариялайды:

| Топик | Түрі | Бұл не |
|---|---|---|
| `/clock` | `rosgraph_msgs/Clock` | Симулятор уақыты |
| `ushqyr/camera/image_raw` | `sensor_msgs/Image` | Камера, `rgb8`, 30 Гц |
| `ushqyr/camera/camera_info` | `sensor_msgs/CameraInfo` | Камера калибрлеуі, әр кадрмен бірге |
| `ushqyr/imu/data_raw` | `sensor_msgs/Imu` | Гироскоп және акселерометр, 500 Гц, бағдарсыз |
| `ushqyr/tof/range` | `sensor_msgs/Range` | Төмен қараған қашықтық өлшегіш; өлшем жоқ кезде `inf` |
| `ushqyr/scan` | `sensor_msgs/LaserScan` | 2D-лидар; 0-сәуле алға қарайды, бұрыштар солға қарай өседі |
| `ushqyr/battery` | `sensor_msgs/BatteryState` | Батарея кернеуі |
| `ushqyr/status` | `ushqyr_msgs/AttemptStatus` | Басқару қадамына бір рет, осы қадамның датчик хабарларынан кейін |
| `ushqyr/info` | `std_msgs/String` | Симулятордың сәлемдесу хабары, JSON түрінде (жаңа жазылушылар үшін сақталады) |

Көпір мыналарды тыңдайды:

| Топик | Түрі | Бұл не |
|---|---|---|
| `ushqyr/rc` | `ushqyr_msgs/RcChannels` | Микросекундпен берілген 16 арна (1000–2000) |
| `ushqyr/joy` | `sensor_msgs/Joy` | Осьтер: крен, тангаж, газ (0..1), рыскание. Батырмалар: 0 арминг, 1 Horizon, 2 Acro |

`RcChannels` арналары: 0 крен, 1 тангаж, 2 газ, 3 рыскание, 4 AUX1 (арминг), 5 AUX2 (ұшу режимі). Арминг тек AUX1 газ
1050-ден жоғары емес кезде көтерілгенде ғана іске қосылады.

Корпустың координаталар жүйесі: x алға, y солға, z жоғары (REP 103). Барлық хабардағы уақыт белгілері симулятор уақыты.

## Камераны калибрлеу

`camera_info` ішінде `K` матрицасы кәдімгі, ал бұрмалану моделі өзгеше: `distortion_model = "ushqyr_radial_k1"`, `D = [k1]`.
Бұл `plumb_bob` **емес**. Модель бұрмаланған кескіндегі нүктені түзу кескінге аударады:
нормаланған координаталарда `x_u = x_d · (1 + k1 · r_d²)`. ROS-тың бұрмалануды түзететін стандартты түйіндері онымен
жұмыс істемейді; формуланы тікелей қолданыңыз (мысал: `color_pid.py` ішіндегі `ColorPid._ray`).

## Уақыт қалай жүреді

Әрекет көпір `ushqyr/rc` немесе `ushqyr/joy` топигіне бірінші хабарды алған кезде басталады (`wait_for_rc` параметрі).
Дайын болмайынша «дизарм» жіберіп тұрыңыз; оған дейін де `ushqyr/info` топигі қолжетімді.

Синхронды режимде көпір әр қадамда датчиктерді жариялайды және жаңа RC хабарын нақты уақыттың `sync_wait` секундынан
ұзақ күтпейді (әдепкі мән 0,2). Хабар келмесе, қадам байланыс үзілгендегідей пакетсіз өтеді; `failsafe_ms` бойы пакет
болмаса, моторлар өшеді.

Түйінге ыңғайлы сұлба: әр `ushqyr/status` хабарына есептеудің бір қадамын жасап, бір RC хабарын жіберу.

Әрекет аяқталғанда `ushqyr/status` хабары `running = false` мәнімен келеді, және көпір жұмысын аяқтайды. Сіздің түйініңіз
де жұмысын аяқтауы керек, әйтпесе контейнер өздігінен тоқтамайды.

## Көпір параметрлері

| Параметр | Әдепкі мән | Бұл не |
|---|---|---|
| `host`, `port`, `token` | ортадан | Симулятор қайда |
| `connect_wait` | 60 | Қосылуға неше секунд тырысу керек |
| `wait_for_rc` | true | Әрекетті бірінші RC хабары бойынша бастау |
| `sync_wait` | 0.2 | Әр қадамда RC хабарын қанша күту керек (синхронды режим) |
| `seed` | берілмеген | Жаттығу режимі: датчик шуының тұқымы (seed) |

## Шешім контейнерінде

Түйіндер тек өз контейнерінің ішінде бір-бірін көреді. ROS 2 журналдары `/tmp` ішіне жазылады, себебі файлдық жүйе тек
оқуға арналған. ROS 2 бар образ шамамен 2,5 ГБ орын алады.

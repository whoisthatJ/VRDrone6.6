# AI Bench: құжаттама

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

AI Bench дегеніміз Ushqyr симуляторының режимі, онда дронды бағдарлама басқарады. Бағдарлама тек борттық
датчиктердің деректерін алады және пульт арналарымен жауап береді. Командалардың бағдарламалары LED-қақпалардан
тұратын трассаны ұшып өтеді; берілген уақыт ішінде қақпа неғұрлым көп болса, орын соғұрлым жоғары.

## Неден бастау керек

1. [Жылдам бастауды](quickstart.md) орындаңыз: мысал трассаны өзі ұшып өтуі керек.
2. [Ережелерді](rules.md) және [дрон және датчиктер](drone.md) бетін оқыңыз.
3. `bench/examples/color_pid` мысалын көшіріп алып, оны өзгертіңіз.
4. Жібермес бұрын шешімді `ushqyr-bench submit-check` командасымен тексеріңіз ([Docker](docker.md)).

## Әлі түпкілікті емес нәрселер

- Ұйымдастырушылар дронының моделі уақытша: ол нақты дрон бойынша калибрленбеген (сәлемдесу хабарында
  `calibrated=false`).
- Шешімдерге арналған шектерді (жад, процессор, образ өлшемі), әрекеттер санын және трассалар санын ұйымдастырушылар
  белгілейді. Осы беттердегі сандар әдепкі мәндер.

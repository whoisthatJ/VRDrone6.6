# Python SDK

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

`ushqyr_bench` пакеті. Бастапқы код: `bench/sdk/python`. Python 3.9 немесе одан жаңа нұсқа қажет; тәуелділіктер:
`numpy`, `msgpack`.

```
pip install ./bench/sdk/python
```

SDK ештеңені жасырмайды және сүзбейді: режим рұқсат етпейтін нәрсені симулятор жай ғана жібермейді. Басқа тілдегі
клиентті [protocol.md](protocol.md) бойынша жазуға болады.

## Қосылу

```python
Sim.connect(host=None, port=None, token=None, truth=False, realtime=True, timeout=30.0, wait=0.0) -> Sim
```

| Аргумент | Мәні |
|---|---|
| `host`, `port`, `token` | Симулятор қайда. Берілмесе, `USHQYR_BENCH_HOST` (`127.0.0.1`), `USHQYR_BENCH_PORT` (`5757`), `USHQYR_BENCH_TOKEN` (бос) орта айнымалыларынан алынады |
| `truth` | Тек жаттығу: әрбір бақылауға шынайы координаттар мен есепті қосу |
| `realtime` | Тек жаттығу: `False` компьютер қаншалықты жылдам есептей алса, соншалықты жылдам есептеуге рұқсат береді. Нәтиже сол күйінде қалады |
| `timeout` | Симулятордың жауабын неше секунд күту керек |
| `wait` | Симулятор іске қосылып жатқанда қосылу талпыныстарын неше секунд қайталау керек. Docker-де `wait=120` қойыңыз |

Іріктеуге арналған шешімде `Sim.connect()` әдісін адрессіз және токенсіз шақырыңыз: сервер оларды орта айнымалылары
арқылы береді.

`Sim` контекст менеджері ретінде жұмыс істейді: `with Sim.connect() as sim:` қосылымды өзі жабады.

## Sim

| Өріс | Бұл не |
|---|---|
| `sim.info` | Симулятордың сәлемдесу хабары: режим, дрон, жиіліктер және камера калибрлеуі бар сөздік (төменде қараңыз) |
| `sim.mode` | `"training"` немесе `"competition"` |
| `sim.control_hz` | Симулятор уақытының бір секундындағы басқару қадамдарының саны (100) |
| `sim.realtime` | `True`, егер симулятор қабырға сағаты бойынша жүріп, `step()` шақыруын күтпесе |
| `sim.running` | `True`, әрекет жүріп жатқанда |
| `sim.status` | `"waiting"`, `"running"`, содан кейін әрекеттің аяқталу себебі |

| Әдіс | Не істейді |
|---|---|
| `sim.reset(seed=None)` | Әрекетті бастайды және бірінші бақылауды қайтарады. Жаттығу: қанша рет болса да, `seed` датчиктер шуын береді. Жарыс: бір рет, `seed` әсер етпейді |
| `sim.step(rc)` | Арналардың бір пакетін жібереді; симулятор бір қадам жасап, бақылауды қайтарады. `sim.step(None)` пакет жоғалған кездегідей пакетсіз қадам жасайды |
| `sim.done()` | Бағдарламаның аяқтағанын хабарлайды. Әрекет `finished` статусымен аяқталады |
| `sim.send(rc)` | Нақты уақыт режимі: пакетті жібереді және ештеңе күтпейді |
| `sim.latest(wait=False)` | Нақты уақыт режимі: келген ең жаңа бақылау немесе `None`. `wait=True` болса, келесісін күтеді |
| `sim.ping(payload=0)` | Тек жаттығу: бір хабар алмасу уақыты, секунд |
| `sim.close()` | Қосылымды жабады |

`reset()` шақырылғанға дейін `step()` шақыруға болмайды: `BenchError("not_started")` шығады.

## RC

```python
RC(roll=0.0, pitch=0.0, throttle=0.0, yaw=0.0, arm=False, mode="angle", aux=())
```

| Өріс | Диапазон | Таңба |
|---|---|---|
| `roll` | -1 … 1 | + оңға |
| `pitch` | -1 … 1 | + алға (тұмсық төмен) |
| `throttle` | 0 … 1 | |
| `yaw` | -1 … 1 | + оңға (жоғарыдан қарағанда сағат тілімен) |
| `arm` | `False` / `True` | AUX1 тумблері |
| `mode` | `"angle"`, `"horizon"`, `"acro"` | AUX2 тумблері |
| `aux` | 10 бүтін санға дейін | қосалқы арналар, симулятор оларды оқымайды |

Диапазоннан тыс мәндер кесіледі. `NaN` нөлге ауыстырылады.

`RC.from_us([1500, 1500, 1000, 1500, 2000, 1000])` арналарды тікелей микросекундпен (1000 … 2000) мына ретпен
береді: roll, pitch, throttle, yaw, AUX1, AUX2.

`rc.channels()` микросекундпен 16 мән қайтарады: симуляторға кететін нәрсе.

## Observation

`reset()`, `step()`, `done()` және `latest()` қайтаратын нәрсе.

| Өріс | Тип | Бұл не |
|---|---|---|
| `obs.t` | float | Старттан бергі симулятор уақыты, секунд |
| `obs.tick` | int | Старттан бергі физика қадамдарының саны (секундына 1000) |
| `obs.running` | bool | `False`, әрекет аяқталғанда |
| `obs.status` | str | `running` немесе аяқталу себебі: `finished`, `time_limit`, `stuck`, `disconnected` |
| `obs.camera` | `Camera` | Соңғы кадр |
| `obs.imu` | `Imu` | Өткен бақылаудан бергі IMU-дың барлық өлшемдері |
| `obs.tof` | `Tof` | Төмен қараған қашықтық өлшегіш |
| `obs.lidar` | `Lidar` | Лидардың соңғы толық айналымы |
| `obs.battery` | `Battery` | Кернеу |
| `obs.truth` | dict немесе `None` | Тек `truth=True` бар жаттығу: `position` және `velocity` метрмен [шығыс, солтүстік, жоғары] ретінде, `points`, `score_time` |

Датчиктер өз жиілігімен жұмыс істейді, сондықтан бақылаулардың көпшілігінде тек IMU өлшемдері жаңа. Қалған
датчиктерде `new` өрісі бар: `True`, егер осы бақылау жаңа мән әкелсе. Жаңасы болмайынша, өрісте өткен мән жатады.

### Camera

| Өріс | Бұл не |
|---|---|
| `image` | `numpy` массиві, биіктік × ен × 3, `uint8`, RGB, жоғарғы жол бірінші. Бірінші кадрға дейін `None` |
| `t` | Кадр түсірілген кездегі симулятор уақыты. Бағдарламаға ол камера кідірісіне кешігіп жетеді |
| `seq` | Кадр нөмірі |
| `new` | Бұл кадр жаңа |

OpenCV үшін түстерді ауыстырыңыз: `cv2.cvtColor(obs.camera.image, cv2.COLOR_RGB2BGR)`.

### Imu

| Өріс | Бұл не |
|---|---|
| `t` | Өлшемдер уақыттарының массиві, ұзындығы n |
| `gyro` | n × 3, рад/с: x оңға крен +, y тұмсық төмен +, z солға бұрылу + |
| `accel` | n × 3, м/с², көрінерлік үдеу: тегіс еденде тыныштықта (0, 0, +9,81) |

`len(obs.imu)` дегеніміз өлшемдер саны (әдетте қадамға 5). Корпус осьтері: x алға, y солға, z жоғары.

### Tof, Lidar, Battery

| Өріс | Бұл не |
|---|---|
| `tof.range`, `tof.valid` | Төмендегі бетке дейін метр; диапазоннан тыс болғанда `0` және `False` |
| `lidar.ranges` | Метрмен қашықтықтар массиві, әр сәулеге біреуден; `0` = ештеңе өлшенбеген; бірінші сканға дейін `None`. `k` сәулесі «алға» осінен `k · angle_step` бұрышқа қарайды, бұрыштар солға қарай өседі |
| `lidar.t` | Айналымның аяқталу уақыты |
| `battery.voltage` | Вольт |
| `.t`, `.new` | Әрқайсысында бар: өлшем уақыты және жаңа мән белгісі |

## Сәлемдесу хабары: sim.info

```python
cam = sim.info["sensors"]["camera"]
fx, fy, cx, cy = cam["fx"], cam["fy"], cam["cx"], cam["cy"]
k1 = cam["distortion"]["k1"]
```

| Кілт | Бұл не |
|---|---|
| `mode`, `time_mode`, `control_hz`, `time_limit` | Режим, `sync` немесе `realtime`, қадам жиілігі, әрекет уақытының шегі |
| `track` | Тек жаттығу: трассаның `id` және `hash` мәндері |
| `drone` | `class` (`ai_mission` немесе `ai_core`), `name`, `calibrated` |
| `rc` | `channels`, `rate_hz`, `latency_ms`, `failsafe_ms` |
| `sensors.camera` | `width`, `height`, `fps`, `hfov_deg`, `tilt_deg`, `latency_ms`, `fx`, `fy`, `cx`, `cy`, `distortion`, `mount` |
| `sensors.lidar` | `rate_hz`, `rays`, `min_m`, `max_m`, `angle_step_deg`. Дронда лидар болмаса, кілт жоқ |
| `sensors.imu`, `sensors.tof`, `sensors.battery` | Жиіліктер мен диапазондар |

## Қателер

`code` және `message` өрістері бар `BenchError`.

| `code` | Қашан |
|---|---|
| `token` | Токен қате |
| `not_allowed` | Хабар бұл режимде тыйым салынған (мысалы, жарыста `ping`) |
| `already_started` | Жарыс режиміндегі екінші старт |
| `attempt_over` | Симулятордың осы іске қосылуының әрекеті аяқталып қойған |
| `not_started` | `reset()` шақырылғанға дейінгі `step()` |
| `timeout` | Симулятор `timeout` секунд ішінде жауап бермеді |
| `disconnected` | Симулятор қосылымды жапты |
| `protocol` | Хабар протоколға сай емес |

Симулятор іске қосылмаған болса, `Sim.connect()` кәдімгі `ConnectionRefusedError` шығарады (немесе `wait` берілсе,
күтеді).

## Нақты уақыт режимі

Ережелерде `time_mode: "realtime"` болса, симулятор қабырға сағаты бойынша жүреді және ешкімді күтпейді. Онда
`step()` пакетті жібереді және жиналып қалғандарын өткізіп жіберіп, ең жаңа бақылауды қайтарады. Өткізіп жіберілген
бақылаулардағы IMU өлшемдері ретімен сақталады. Өз цикліңіз үшін `send()` және `latest()` әдістерін қолданыңыз.

## Симуляторсыз тесттер

`ushqyr_bench.fake.FakeSim` дегеніміз кодыңыздың модульдік тесттеріне арналған симулятор бітеуіші:

```python
from ushqyr_bench import Sim, RC
from ushqyr_bench.fake import FakeSim

with FakeSim() as fake, Sim.connect(port=fake.port) as sim:
    obs = sim.reset()
    obs = sim.step(RC(arm=True))
    assert fake.received[-1][4] == 2000     # AUX1
```

Ол шағын сұр кадрлар (64 × 48) береді және ұшуды модельдемейді: онымен алгоритм емес, алмасу тексеріледі.

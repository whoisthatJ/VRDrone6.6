# Жылдам бастау

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

30 минутта: симулятор мен SDK-ны орнату, трассаны өзі ұшып өтетін дайын мысалды іске қосу және алғашқы өз
бағдарламаңызды жазу. Қалған беттер: [README.md](README.md).

Бағдарлама тек дрон датчиктері беретін деректерді алады (аналогтық шуы бар FPV-камера кескіні, IMU, ToF қашықтық
өлшегіші, LiDAR, батарея кернеуі) және пульт арналарымен жауап береді: throttle, roll, pitch, yaw. Дрон мен
қақпалардың координаттарын ол алмайды.

## Не қажет

| | Windows | Linux |
|---|---|---|
| Жүйе | Windows 10 немесе 11, 64 бит | Ubuntu 22.04 немесе 24.04, 64 бит |
| Бейнекарта | GTX 1650 деңгейінде немесе одан жақсы | сол сияқты, драйвері орнатылған |
| Python | 3.9 немесе одан жаңа | 3.9 немесе одан жаңа |
| Интернет | `pip install` үшін | `pip install` үшін |

Қатысушы жинағы дегеніміз симуляторы (`Ushqyr.exe` немесе `Ushqyr.x86_64`) және `bench` бумасы (SDK, мысалдар,
шешім үлгісі, құралдар) бар бума. Төмендегі барлық командалар осы бумада орындалады.

## 1. SDK-ны орнатыңыз (5 минут)

Windows (PowerShell немесе cmd):

```
py -m venv .venv
.venv\Scripts\activate
pip install ./bench/sdk/python opencv-python
```

Linux:

```
python3 -m venv .venv
source .venv/bin/activate
pip install ./bench/sdk/python opencv-python
```

SDK тек `numpy` мен `msgpack` пакеттеріне тәуелді. OpenCV SDK-ға емес, мысалға қажет.

## 2. Симуляторды AI Bench режимінде іске қосыңыз (2 минут)

Қатысушы жинағындағы симуляторды іске қосыңыз: ол бірден AI Bench режимін ашады.

- Windows: `Ushqyr.exe`
- Linux: `chmod +x Ushqyr.x86_64`, содан кейін `./Ushqyr.x86_64`

Ойынның толық нұсқасында басты мәзірде **AI Bench** батырмасын басыңыз немесе оны `-bench` кілтімен іске қосыңыз.

`H1_Oval` трассасы бар зал ашылады (сопақша бойымен 6 қақпа). Сол жақ жоғарыда «Бағдарлама күтілуде, порт 5757»
деп жазылған. Дрон старт алаңында тұр.

## 3. Мысалды іске қосыңыз (3 минут)

Терминалдың екінші терезесінде (`.venv` ортасын қайта қосуды ұмытпаңыз):

```
python bench/examples/color_pid/color_pid.py --show
```

Дрон ұшып көтеріледі, қақпаларды жарықтандыру (LED) түсі бойынша тауып, шеңбер бойымен ұшады. Не көресіз:

- сол жақ жоғарыда: қақпалар есептегіші және әрекет уақыты;
- оң жақ төменде: борттық камераның кескіні, дәл бағдарлама алатын кескін;
- бөлек терезеде (`--show` кілті): сол кескін, табылған қақпаның айналасында жақтауы бар.

**C** пернесі көріністі ауыстырады: дронның артындағы камера немесе залдың жалпы көрінісі. Ойынның толық нұсқасында **Esc** мәзірге
қайтарады.

Әрекет 120 секундқа созылады. Бір айналымнан кейін тоқтау үшін `--points 6` қосыңыз.

Мысалдың қалай құрылғаны `bench/examples/color_pid/README.md` файлында сипатталған.

## 4. Өз бағдарламаңызды жазыңыз (10 минут)

`my_first.py` деп сақтап, мысал сияқты іске қосыңыз:

```python
from ushqyr_bench import Sim, RC

with Sim.connect() as sim:
    obs = sim.reset()                       # дрон стартта, уақыт нөлден
    for _ in range(15):                     # арминг: тумблер өшірулі...
        obs = sim.step(RC(arm=False))
    for _ in range(15):                     # ...содан кейін нөлдік газда қосулы
        obs = sim.step(RC(arm=True))
    while sim.running:
        frame = obs.camera.image            # numpy, 480 x 640 x 3, RGB
        gyro, accel = obs.imu.gyro, obs.imu.accel
        height = obs.tof.range              # еденге дейін метр, егер obs.tof.valid
        scan = obs.lidar.ranges             # шеңбер бойымен 360 қашықтық, 0 = ештеңе өлшенбеген
        rc = RC(throttle=0.56, pitch=0.1, arm=True)   # мұнда сіздің алгоритміңіз
        obs = sim.step(rc)                  # симулятор бір қадам жасайды (1/100 с)
```

Басқару туралы маңызды нәрселер:

- Арналар нағыз пульттегідей. `roll`, `pitch`, `yaw` -1-ден 1-ге дейін, `throttle` 0-ден 1-ге дейін.
- **Арминг.** Ұшу контроллері моторларды `arm` тумблері газ түсірулі кезде «өшірулі» күйден «қосулы» күйге
  ауыстырылғанда ғана қосады. Алдымен `arm=False` бар бірнеше пакет жіберіңіз, содан кейін `arm=True` және
  `throttle=0`, тек содан кейін газ қосыңыз.
- Әдепкі режим Angle (дрон көкжиекті өзі ұстайды): `pitch=0.2` дегеніміз шамамен 9 градусқа алға еңкею.
- Қалқып тұру газы шамамен 0.56.
- Симулятордағы уақыт тек сіздің `step()` шақыруларыңызбен жүреді. Бағдарлама ұзақ ойланса, ұшу жай ғана баяу
  жүреді, нәтиже бұдан өзгермейді.

Әрі қарай `color_pid.py` көшірмесінен бастаңыз: `GateDetector` класы қақпаларды іздейді, `ColorPid` класы
басқарады. SDK-ның барлық класстары [sdk.md](sdk.md) бетінде сипатталған.

## 5. Жаттығу режимі

Әдепкі бойынша симулятор жаттығу режимінде жұмыс істейді. Онда қосымша мыналар қолжетімді:

- `sim.reset()` қанша рет болса да, шу тұқымын (seed) таңдаумен: `sim.reset(seed=7)`;
- жөндеуге арналған шынайы координаттар мен есеп: `Sim.connect(truth=True)`, содан кейін `obs.truth`;
- жеделдетілген орындау: `Sim.connect(realtime=False)`.

Жарыс режимінде бұлардың ешқайсысы жоқ. Мысалды бірнеше шу тұқымында (seed) тексеру:

```
cd bench/examples/color_pid
python evaluate.py --runs 10
```

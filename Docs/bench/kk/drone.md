# Дрон және датчиктер

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

Осы беттегі сандар әдепкі мәндер. Ағымдағы іске қосудың нақты мәндері әрқашан симулятордың сәлемдесу хабарында
келеді: `sim.info` ([sdk.md](sdk.md) қараңыз). Оларды кодқа қатырып жазбай, сол жерден оқыңыз.

## Екі класс

| Класс | Дрон | Кім белгілейді |
|---|---|---|
| **AI MISSION** | Ұйымдастырушылардың вупері, барлығына бірдей | Ұйымдастырушылар |
| **AI CORE** | `drone.yaml` файлында сипатталған команданың өз дроны | Команда, класс шектері аясында |

## Вупер (AI MISSION)

| | |
|---|---|
| Өлшемі | 65 мм, 4 мотор, винттері қорғаныста |
| Массасы | 32 г |
| Батарея | 1S |
| Тартудың салмаққа қатынасы | шамамен 3 : 1 |
| Қалқып тұру газы | шамамен 0,56 |
| Соқтығысу радиусы | 4,5 см |

**Модель уақытша.** Ол ұйымдастырушылардың нақты дроны бойынша калибрленбеген: сәлемдесу хабарында
`drone.calibrated = false` тұр. Калибрлеуден кейін тарту, инерция және кедергі өзгереді, сондықтан шешімді бүгінгі
сандарға тым дәл бейімдемеңіз.

## Басқару

Бағдарлама нағыз таратқыш сияқты пульт арналарын жібереді. Моторларға тікелей команда беру қолжетімсіз.

| Арна | Бұл не | SDK-дағы диапазон |
|---|---|---|
| Roll | крен, + оңға | -1 … 1 |
| Pitch | тангаж, + алға (тұмсық төмен) | -1 … 1 |
| Throttle | газ | 0 … 1 |
| Yaw | тік осьті айнала бұрылу, + оңға (жоғарыдан қарағанда сағат тілімен) | -1 … 1 |
| AUX1 | арминг | өшірулі / қосулы |
| AUX2 | ұшу режимі | `angle`, `horizon`, `acro` |

| | |
|---|---|
| Басқару қадамының жиілігі | 100 Гц |
| Басқару арнасының кідірісі | 10 мс |
| Failsafe | 500 мс пакетсіз: моторлар қайта армингке дейін ажыратылады |

**Ұшу режимдері.** Angle: дрон көкжиекті өзі ұстайды, стик еңкею бұрышын береді. Horizon: стик центріне жақын
жерде сол сияқты, шеттерінде дрон айналады. Acro: стик айналу жылдамдығын береді, дрон көкжиекті ұстамайды.

**Арминг.** Моторлар AUX1 газ нөлге жақын кезде «өшірулі» күйден «қосулы» күйге өткенде ғана қосылады.

## Камера

| | |
|---|---|
| Кадр | 640 × 480, RGB, арнасына 8 бит |
| Жиілігі | секундына 30 кадр |
| Көру бұрышы | көлденеңінен 120°, шетінен шетіне дейін |
| Еңісі | 20° жоғары |
| Кідіріс | түсіруден бағдарламаға дейін 30 мс |
| Объектив бұрмалануы | бөшке тәрізді, `k1 = 0,18` |
| Экспозиция | автоматты |

**Объектив.** `x_d = (u - cx) / fx`, `y_d = (v - cy) / fy`, `r² = x_d² + y_d²` болсын. Сонда шынайы бұрыштардың
тангенстері: `x_u = x_d · (1 + k1 · r²)`, `y_u = y_d · (1 + k1 · r²)`. `fx, fy, cx, cy, k1` мәндері сәлемдесу
хабарында келеді. Есептеу мысалы: `color_pid.py` файлындағы `ColorPid._ray` әдісі.

**Аналогтық бейнеарна.** Кескін аналогтық бейнебайланыс моделінен өтеді: жұмсақ бөлшектер, жайылған және жылжымалы
түс, шу, секіретін жолдар және үзілген жолақтар. Дрон старт алаңынан (қабылдағыш сонда тұр) неғұрлым алыс болса
және олардың арасында кедергі неғұрлым көп болса, кескін соғұрлым нашар. Таза кадрларда үйретілген детектор мұндай
кескінде қателеседі: оны симулятор кадрларында үйретіңіз ([dataset.md](dataset.md)).

## IMU

| | Гироскоп | Акселерометр |
|---|---|---|
| Жиілігі | 500 Гц | 500 Гц |
| Бірліктері | рад/с | м/с² |
| Шу (бір ауытқу) | 0,004 | 0,08 |
| Әрекет бойындағы тұрақты ығысу | 0,003 | 0,04 |
| Шегі | 2000 °/с | 16 g |

- Корпус осьтері: x алға, y солға, z жоғары.
- Гироскоп: x оңға крен +, y тұмсық төмен +, z солға бұрылу +.
- Акселерометр көрінерлік үдеуді өлшейді: тегіс еденде тыныштықта ол (0, 0, +9,81) көрсетеді.
- Моторлардың дірілінен шу өседі: айналым неғұрлым жоғары болса, екі датчик те соғұрлым шулы.
- IMU бағдарды (бұрыштарды) бермейді. Оны өзіңіз есептеуіңіз керек.

Басқарудың бір қадамында IMU-дың 5 өлшемі келеді.

## ToF қашықтық өлшегіші

| | |
|---|---|
| Бағыты | төмен |
| Жиілігі | 50 Гц |
| Диапазоны | 0,05 … 4 м |
| Шу | 5 мм + қашықтықтың 1% |

Диапазоннан тыс жерде `valid = false`, ал `range = 0`.

## LiDAR

| | |
|---|---|
| Түрі | 2D, дронның өзінің көлденең жазықтығында |
| Сәулелер | 360, қадамы 1° |
| Жиілігі | секундына 10 айналым |
| Диапазоны | 0,15 … 12 м |
| Шу | 1 см + қашықтықтың 0,5%; сәулелердің 0,5% жоғалады |

`k` сәулесі «алға» осінен `k` градусқа қарайды, бұрыштар солға қарай өседі (жоғарыдан қарағанда сағат тіліне
қарсы). 0 мәні «ештеңе өлшенбеген» дегенді білдіреді. Бір айналымның сәулелері дрон қозғалып бара жатқанда кезекпен
түсіріледі, сондықтан ұшу кезінде түсірілген скан қисайған болады. Дрон еңкейгенде скан жазықтығы онымен бірге
еңкейеді және еденге тиюі мүмкін.

## Батарея

Кернеу, секундына 10 рет. Жүктеме кезінде кернеу төмендейді, әрекеттің соңына қарай түседі, онымен бірге тарту да
түседі.

## Өз дроныңыз (AI CORE)

Дронды `drone.yaml` файлында сипаттаңыз: өлшемі, массасы, моторлардың тартуы мен инерциялылығы, винттер, батарея,
контроллер шектері, камераның еңісі мен көру бұрышы, датчиктер жиыны. Түсініктемелері бар үлгі:
`bench/examples/drones/example_3inch.yaml`.

```
ushqyr-bench validate-drone drone.yaml
Ushqyr.exe -bench -bench-drone drone.yaml
```

Класстың әдепкі шектері (ұйымдастырушылар оларды өзгерте алады):

| Параметр | Шек |
|---|---|
| Өлшемі | 300 × 300 × 180 мм-ден артық емес |
| Массасы | 25 … 1500 г |
| Тартудың салмаққа қатынасы | 1,5 … 8 |
| Батарея | 6 банкаға дейін, 2200 мА·сағ дейін |
| Мотордың уақыт тұрақтысы | 10 мс-тен кем емес |
| Айналу жылдамдығы | 1000 °/с дейін |
| Angle режиміндегі еңкею бұрышы | 70° дейін |
| Камера еңісі | 0 … 60° |
| Камераның көру бұрышы | 60 … 150° |
| Датчиктер | `camera, imu, tof, lidar, battery` жиынынан |

Бұл қалай жұмыс істейді:

- Масса, тарту, моторлардың инерциялылығы, батарея және шектер файлдан сол күйінде алынады. Инерция, кедергі және
  контроллер коэффициенттері өлшем мен массадан есептеледі: олар арқылы «физикаға сай емес» дронды жариялау мүмкін
  емес.
- Симулятор файлды жүктеу кезінде `validate-drone` қолданатын ережелермен тексереді және оларды бұзатын дронды
  қабылдамайды. Себептері сөзбен жазылған.
- `sensors` тізімінде жоқ датчик жіберілмейді.
- Соқтығысулар шар бойынша есептеледі, оның өлшемі дронның жарияланған өлшеміне сәйкес келеді.
- Файл қарапайым YAML: кірістірілген кілттер шегіністермен, сандар, мәтін және бір жолдағы тізімдер `[a, b, c]`.

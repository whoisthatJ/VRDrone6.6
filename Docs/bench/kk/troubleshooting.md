# Бірдеңе жұмыс істемесе

> Аударма ана тілді маманның тексеруін қажет етеді. Негізгі мәтін: орыс тіліндегі нұсқа.

## Орнату

| Не көресіз | Не істеу керек |
|---|---|
| `python` немесе `pip` табылмады (Windows) | Python-ды python.org сайтынан орнатып, `py -m venv .venv`, `py -m pip ...` қолданыңыз |
| `error: externally-managed-environment` (Linux) | Виртуалды ортаға орнатыңыз: `python3 -m venv .venv`, `source .venv/bin/activate` |
| `ModuleNotFoundError: ushqyr_bench` | `.venv` ортасы қосылмаған немесе SDK орнатылмаған: `pip install ./bench/sdk/python` |
| `ModuleNotFoundError: cv2` | `pip install opencv-python` |
| `ushqyr-bench` табылмады | Сол ортада `pip install ./bench/runner` |
| Симулятор Linux-та іске қосылмайды | `chmod +x Ushqyr.x86_64`; бейнекарта драйвері орнатылғанын тексеріңіз |

## Қосылу

| Не көресіз | Не істеу керек |
|---|---|
| `ConnectionRefusedError` | Симулятор AI Bench режимінде іске қосылмаған: мәзірде **AI Bench** батырмасын басыңыз немесе `-bench` кілтімен іске қосыңыз. Экранда «Бағдарлама күтілуде, порт 5757» деген жазу болуы керек |
| 5757 порты бос емес | `Ushqyr.exe -bench -bench-port 5800`, ал бағдарламаға `USHQYR_BENCH_PORT=5800` беріңіз |
| `BenchError: token` | Симулятор токенмен іске қосылған (`-bench-token`). Сол токенді `USHQYR_BENCH_TOKEN` айнымалысына беріңіз |
| `BenchError: attempt_over` | Жарыс режимінде симулятордың бір іске қосылуы дегеніміз бір әрекет. Симуляторды қайта іске қосыңыз |
| `BenchError: already_started` | Жарыс режимінде `reset()` бір рет шақырылады |
| `BenchError: not_allowed` | Хабар жарыс режимінде тыйым салынған (мысалы, `ping`) |
| Екінші бағдарлама біріншісін «ығыстырып шығарды» | Симуляторға бір бағдарлама қосылады. Жаңа қосылым ескісін алмастырады |

## Ұшу

| Не көресіз | Не істеу керек |
|---|---|
| Дрон тұр, моторлар үнсіз | Арминг орындалмаған. Алдымен `arm=False` бар пакеттер, содан кейін `throttle=0` кезінде `arm=True`, тек содан кейін газ |
| Моторлар ұшу кезінде өшіп қалды | Failsafe: 500 мс пакет болмады. `step()` әдісін әр қадамда шақырыңыз. Моторларды қайта қосу үшін нөлдік газда `arm` тумблерін өшіріп, қайта қосыңыз |
| Дрон ұшып көтеріліп, құлайды | Қалқып тұру газы шамамен 0,56. Биіктікті `obs.tof.range` бойынша ұстаңыз |
| Дрон артқа немесе бүйірге ұшады | Таңбаларды тексеріңіз: `pitch` + алға, `roll` + оңға, `yaw` + оңға |
| Әрекет `stuck` статусымен аяқталды | Дрон 10 секунд қозғалмады. Әдетте ол соққыдан кейін жатады немесе бағдарлама газ бермейді |
| Әрекет `timeout` статусымен аяқталды | Бағдарлама қадамға нақты уақыттың 10 секунды ішінде жауап бермеді. Қатып қалуды немесе тым ұзақ есептеуді іздеңіз |
| `obs.camera.image` мәні `None` | Кадрлар әлі болған жоқ. Біріншісі `reset()` шақыруынан кейінгі бірінші бақылаумен келеді |
| OpenCV-де кадр түстері шатасқан | Кадр RGB форматында, ал OpenCV BGR күтеді: `cv2.cvtColor(image, cv2.COLOR_RGB2BGR)` |
| Кескіндегі қақпалар шеттерінде «майысады» | Бұл объективтің бөшке тәрізді бұрмалануы. Формула [drone.md](drone.md) бетінде бар |
| Детектор старттан алыста қақпаларды нашар табады | Аналогтық бейнеарна қашықтыққа қарай нашарлайды. Детекторды симулятор кадрларында үйретіңіз ([dataset.md](dataset.md)) |
| Ұшу нақты уақыттан баяу жүреді | Синхронды режимде симулятор сіздің бағдарламаңызды күтеді. Бұл нәтижеге әсер етпейді |
| Бір іске қосу әр жолы әртүрлі нәтиже береді | Тұқымның (seed) бірдей екенін (`sim.reset(seed=...)`) және бағдарламаның өзі кездейсоқтықты немесе қабырға сағатын қолданбайтынын тексеріңіз |

## Docker

| Не көресіз | Не істеу керек |
|---|---|
| `the Docker engine is not running` | Docker Desktop-ты (Windows) немесе Docker қызметін (Linux) іске қосыңыз |
| `the base image ... is not built yet` | `ushqyr-bench build-images` |
| `the attempt produced no result` | Шешім қосылмады немесе құлады. `--logs` кілтімен шығысты қараңыз |
| `the solution did not exit when the attempt ended` | Бағдарлама өзі аяқталуы керек: `sim.running` мәні `False` болғанда циклден шығыңыз |
| Ұшу кезінде `pip install` немесе салмақтарды жүктеу қатесі | Контейнерде интернет жоқ. Барлығын `Dockerfile` ішінде орнатыңыз, салмақтарды образға салыңыз |
| `Read-only file system` | Тек `/tmp` бумасына жазуға болады |
| Шешім жад бойынша тоқтатылды | Шек 4 ГБ. Модельді немесе пакет өлшемін азайтыңыз |
| Тексеру ондаған минутқа созылады | Симулятор бейнекартасыз сурет салады. [docker.md](docker.md) бетіндегі «Уақыт» бөлімін қараңыз |
| Шешім симулятор дайын болғанға дейін қосылады | `Sim.connect(wait=120)` |

## ROS 2

| Не көресіз | Не істеу керек |
|---|---|
| Топиктер жоқ | Көпір іске қосылмаған немесе қосылмады: `USHQYR_BENCH_HOST`, `USHQYR_BENCH_PORT` мәндерін және симулятордың AI Bench режимінде екенін тексеріңіз |
| Әрекет басталмайды | Көпір `ushqyr/rc` немесе `ushqyr/joy` топигіндегі бірінші хабарды күтеді |
| Моторлар ажыратылады | Түйін командаларды тым сирек жібереді: көпір команданы қадамға 0,2 с-тан артық күтпейді, содан кейін қадам пакетсіз жүреді |
| Бұрмалануды стандартты түзету қате кескін береді | Бұрмалану моделі `plumb_bob` емес. [ros2.md](ros2.md) қараңыз |
| Контейнер әрекеттен кейін аяқталмайды | `ushqyr/status` `running = false` мәнімен келгенде сіздің түйініңіз аяқталуы керек |

## Көмектеспесе

Мыналарды жинап, ұйымдастырушыларға жіберіңіз:

- симулятор нұсқасын (ол сәлемдесу хабарында бар: `sim.info["sim"]`) және операциялық жүйені;
- іске қосқан команданы және қатенің толық мәтінін;
- Docker үшін: `ushqyr-bench submit-check ... --logs` шығысын.

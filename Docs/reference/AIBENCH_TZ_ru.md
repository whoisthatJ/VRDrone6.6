# ТЗ на симулятор, коротко (режим AI Bench)

> Исходный текст задания, как получен. Сохранить в проекте как `Docs/reference/AIBENCH_TZ_ru.md`. Это источник требований для `AIBENCH_PLAN.md`.

**Цель.** В нашем симуляторе нужен режим, где команды тренируют автономные алгоритмы полета через ворота, а мы проводим на нем онлайн-отбор.

**Трасса.** Ворота по стандарту: 250 x 250 см, проем 195 x 195 см, у каждых ворот своя LED-подсветка. Нужны редактор трасс, 5+ готовых трасс и скрытые трассы для отбора. Площадки: зал и паркинг.

**Дроны.** Для AI MISSION нужна модель нашего вупера с реальными массой, тягой и задержками. Для AI CORE нужен дрон команды до 30 x 30 x 18 см, параметры задаются в конфиге.

**Сенсоры.** FPV-камера с шумом аналога, IMU, ToF, LiDAR, напряжение батареи. GPS и координат дрона нет.

**API.** Python SDK и мост ROS 2. Управление идет каналами пульта (throttle, roll, pitch, yaw), как через реальный TX. Задержка связи настраивается. Нужен готовый пример решения: детектор по цвету плюс PID.

**Очки.** Ворота засчитываются автоматически: 1 очко за каждые. Повтор тех же ворот засчитывается только после 4 других. При равенстве очков выше команда с меньшим временем. Нужен лидерборд с выгрузкой в CSV.

**Защита от нечестной игры.** В режиме соревнования нет ground-truth и ручного управления. Решение команды работает в Docker. Логи защищены контрольной суммой.

**Обучение.** Генерация датасетов с разметкой в форматах YOLO и COCO. Рандомизация света, фона и шума.

**Запись.** Видео с борта и со стороны трассы, логи в CSV или JSON, повтор попытки для судей.

**Пакетный запуск.** Решения всех команд запускаются на сервере без графики, по нескольким трассам, результаты собираются в один файл.

**Платформы.** Windows и Linux. Документация на русском, казахском и английском.

**Сроки.**
- к 17 ноября: демо (трасса, вупер, API, пример решения);
- до [дата]: очки, режим соревнования, логи;
- до [дата]: AI CORE, ROS 2, Docker, пакетный запуск;
- перед отбором: тест с 3-5 командами.

**Приемка.**
- пример решения проходит трассу сам;
- очки сходятся с ручной проверкой по видео;
- координат дрона и ворот через API не достать;
- 20 решений на 3 трассах прогоняются без ручного вмешательства;
- новая команда по документации ставит симулятор и запускает пример за 30 минут.
